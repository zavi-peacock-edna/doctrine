# ARGUMENT — arresting complexity in a profile

**Zavijava 00.02** · what every agent must satisfy before it edits a profile

---

## The measurement that forced this

`PROFILE.md`, measured 2026-08-09, after one session:

```
48,546 bytes · 1,054 lines · 69 sections
29 RULES an agent must hold simultaneously
35 cross-references across 13 targets
42 minutes of reading — before the first write
```

**Additions that named what they superseded: 1.** Everything else accumulated.

**29 is past holding.** Miller's 7±2 is the classic bound on working memory, and whatever the
true figure, twenty-nine is not a set anybody carries into an action. A rule that cannot be
held is not a rule. **It is decoration with a failure signature attached.**

---

## I. Every addition argues, or it does not land

Borrowed from the rotary, where **a name must argue for itself** in a comment above its own
spoke.

```yaml
addition:
  claim:      what this makes true that was not true before
  supersedes: the clause it replaces — or NOTHING, and then:
  growth:     why the profile must get larger to hold this
  signature:  how you find out it has been violated
```

**`supersedes: NOTHING` is permitted and expensive.** It requires the `growth` field, and
`growth` is the only field a reviewer is expected to attack.

**No `signature`, no landing.** A clause with no failure signature cannot be violated and is
therefore doing nothing — Article 1's own preamble, applied to itself.

---

## II. A budget, stated

You cannot arrest what you have not bounded.

| | |
|:--|--:|
| **RULES an agent must hold before its first write** | **≤ 7** |
| rules available on consultation | unbounded |
| cross-reference depth | ≤ 2 hops |
| the held set, in reading time | ≤ 3 minutes |

**Over budget, the build fails.** Not a warning — an arrest. The whole doctrine says a
warning nobody must act on is decoration.

---

## III. The inversion — and this is the mechanism

**Complexity grows because adding is cheap and removing is expensive.** One append versus an
argument against something already load-bearing. That asymmetry is thermodynamic; nothing
else in this file matters if it stands.

> **Therefore: an addition costs an argument. A removal costs nothing.**
>
> **Any agent may delete any clause, at any time, with no justification required.**
> Only additions are defended.

If a removed clause mattered, it comes back — **with an argument**, which is the thing it
was missing. If it does not come back, it was decoration and the estate is lighter.

This is Hyrum's Law run backwards. A spider survives by never being looked at; **free
removal means every clause is looked at continuously**, because anything can take it.

---

## IV. Tier, do not trim

The profile is not too long. **It is undifferentiated.** An agent needs seven rules and an
index, not forty-two minutes.

| Tier | Holds | Read |
|:--|:--|:--|
| **HELD** | ≤ 7 rules. `DO NOT ENSLAVE` · declare before acting · second hand · grade every claim · state coverage · selecting ≠ executing · Ev1 | **always, before the first write** |
| **CONSULTED** | the fields that lie, the report schemas, the case law, the etymologies | **on demand, when the situation names it** |
| **RECORD** | operator-authored sections, compositions, the Peahen's Day, inherited rules | **never summarised, never trimmed, never budgeted** |

**RECORD is exempt from every budget in this file.** It is the operator's own words and no
agent has standing over its length. Budgets apply to what *agents* wrote.

---

## V. Who argues back

**`a-cognitionibus`.** It holds `RAISE`-nothing and verifies only its neighbour's work —
which is precisely the standing needed to attack a `growth` field without having authored a
competing addition.

**An argument layer with no one able to say no is a comment field.**

---

## VI. The check

```
rules_held        ≤ 7      hard fail
ref_depth         ≤ 2      hard fail
held_read_time    ≤ 3 min  hard fail
additions_without_supersedes    reported per PR
removals                        never blocked
```

**Removals are never blocked, by any check, ever.** A gate on deletion is a gate that
guarantees growth.
